What changed from v1

  • Every row has a label next to its dot (ok, exit 101, running…). That's the andon rule: never color alone.
  • Edit diffs have no line numbers: the tool input only carries old_string and new_string, with no position in the file. Any context lines are whatever claude included in old_string.
  • The Task card nests its subagent's calls one level deep, between its prompt and its result. Shown open here; it starts collapsed.
  • Generic fallback (WebFetch here): the target is the input summary, and the body is pretty-printed input, then the output.
